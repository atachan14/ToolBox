# Progress Help

CSS の進捗値に応じて値を変化させる `clamp(...)` / `calc(...)` コードを作るツールです。
スクロール進捗やアニメーション進捗など、1 つの変数を基準にサイズ・位置・透明度などを補間したいときに使います。

## 基本の流れ

1. `segments` の表に変数名、進捗範囲、値の範囲を入力する
2. `code` に生成された CSS を確認する
3. `code` 欄をクリックしてクリップボードへコピーする

入力内容はタブごとに保存されます。

## Segments

1 行が 1 つの変化区間です。
空欄のままにした項目は、生成時に既定値として扱われます。

- `var`: 進捗を表す CSS カスタムプロパティ名。空欄の場合は `--p`
- `start p`: 変化を開始する進捗値。空欄の場合は `0`
- `end p`: 変化を終了する進捗値。空欄の場合は `1`
- `start v`: 開始時の値。空欄の場合は `0`
- `end v`: 終了時の値。空欄の場合は `100`

`start v` と `end v` には `px`、`%`、`rem` などの単位付きの値も入力できます。
両方の単位が同じ場合は、差分を計算した式として出力されます。

## Segment の追加と削除

- `add segment`: 新しい行を追加します
- 行を右クリックして `delete segment`: 対象の行を削除します

Segment が 1 行だけの場合は削除できません。

## Code

`segments` を編集すると、下の `code` 欄に CSS が自動生成されます。

- Segment が 1 行の場合は `clamp(...)` を出力します
- Segment が複数行の場合は、各 Segment の `clamp(...)` を `calc(...)` で合成して出力します
- `code` 欄をクリックすると、現在のコードをクリップボードへコピーします

`var` に `p` と入力した場合、CSS では `--p` として出力されます。
`--scroll` のように `--` 付きで入力しても、そのまま CSS カスタムプロパティとして扱われます。

## 履歴

- `履歴を保存`: 現在の Segment と生成コードを履歴に保存します
- `履歴を表示`: 保存済みの履歴を一覧表示します
- 履歴項目をクリック: コードをコピーし、その履歴の Segment を現在の表へ戻します
- 履歴項目を右クリックして削除: 履歴から対象項目を削除します

履歴は最大 50 件まで保存されます。

## Reset

`リセット` は Segment を 1 行の初期状態に戻します。
履歴は削除されません。

## 例

`--p` が `0` から `1` に進む間に、値を `20px` から `80px` へ変化させたい場合:

- `var`: `p`
- `start p`: `0`
- `end p`: `1`
- `start v`: `20px`
- `end v`: `80px`

生成されたコードを CSS の値として貼り付けて使います。
