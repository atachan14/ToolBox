
# progress概要
HTML/CSSにおける（主に）スクロールアニメーション作成の補助ツール

# 仕様
## 全体のレイアウト

segments
    segment_tab
        progress変数 [input]
        start p [input]
        start v [input]
        end p [input]
        end v [input]
        easing [select]
            linear
            ease
            ease-in
            ease-out
            ease-in-out
            custom
        custom easing [input]
    add_tab
code(result)

## segments
segmentをタブで保有する。
デフォルトでは空のsegmentひとつとadd_tabだけ

## segment_tab
タブにはindexを自動で表示(1,2,3,4...)
値を入力するとcodeに反映される。
値が入ってないときはデフォルト値を使用する。
以下がデフォルト値
    progress変数 : p
    start p : 0
    start v : 0
    end p : 1
    end v : 100
    easing : liner

## segment内のinput
pは数字のみ
vは単位も一緒に入力可(codeでの出力用)

## add_tab
タブには"+"と表示
segment_tabを追加する。

## code
クリックでコピー
